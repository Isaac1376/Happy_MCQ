<h1 align="center">🎯 Happy MCQ Application</h1>

<p align="center">
A modern and responsive quiz application built using <b>HTML, CSS, and JavaScript (React + Vite)</b> for competitive exam preparation.
</p>

<h2>📌 Features</h2>
<ul>
  <li>🧠 Topic-wise Multiple Choice Questions</li>
  <li>⏱️ Timer-based exam simulation</li>
  <li>📊 Instant score calculation</li>
  <li>📱 Fully responsive design</li>
  <li>🎨 Modern UI with glass effect</li>
  <li>⚡ Fast performance using Vite</li>
</ul>

<h2>▶️ Getting Started</h2>

<h3>1. Clone the repository</h3>
<pre>
git clone https://github.com/YOUR_USERNAME/Happy_MCQ.git
cd Happy_MCQ
</pre>

<h3>2. Install dependencies</h3>
<pre>
npm install
</pre>

<h3>3. Run locally</h3>
<pre>
npm run dev
</pre>

<hr>

<h2>🚀 Deployment</h2>

<pre>
npm run build
npm run deploy
</pre>
